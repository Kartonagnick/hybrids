#67-dev-logg
============
В этой задаче нужно изготовить логгер, 
который перенаправляет вывод одновременно и в консоль, и файл:  

```vbs
dim g_logg: set g_logg = new CFileLogger

sub echo(deep, msg)
  g_logg.echo deep, msg
end sub
        
sub dbg(deep, msg)
  g_logg.dbg deep, msg
```

Особенности:  
1. не конфликтует с `echo.vbs`  
2. упраздняет `echo.vbs`  

Таким образом, если подключать одновременно с `echo.vbs`, ничего не сломается.  
Но использование `logg.vbs` делает `echo.vbs` не нужным.

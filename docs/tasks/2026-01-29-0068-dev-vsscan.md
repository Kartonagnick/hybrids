#68-dev-vsscan
==============
Задача под заказ проектов Bolid  
Инструмент для формирования списка исходников для проектов Banana.Props  
Можно запускать из каталога стеша, или из каталога репозитория.  

Управляющие переменные:  
```
eDEBUG=ON"
eDIR_WORK=."
```

Алгоритм работы скрипта:  

1. `CSettings` находит:  
   - каталог-стеш  
   - каталог репозитория  
   - солюшены студии  

2. для каждого `CSolution` выполняется поиск `CProject`  

3. Для каждого `CProject` формирукется:  
   - `проект.vcxproj.filters`
   - `sources.props`

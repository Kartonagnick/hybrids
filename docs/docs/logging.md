[![S]][M] logging v0.0.1
=========================
Инструмент служит для вывода логов одновременно и в консоль, и в файл.  
Пример использования:  
```vbs
  g_logg.echo 0, "main(1): running"
  g_logg.echo 0, "main(1): done"
  g_logg.close
```

Другой вариант использования:  
```vbs
  echo 0, "main(1): running"
  echo 0, "main(1): done"
```
Логгер автоматически переопределяет глобальную функцию echo,
перенаправляя копию данных в файл.  
<br/>


Управление логгером
-------------------  

| **ID**              | описание                                         |
|:-------------------:|:------------------------------------------------:|
|  eLOG.SYSTEM_LOCALE | вкл/выкл системную локаль. по умолчанию: utf-8   |
|  eLOG.FLUSH         | не используется                                  |
|  eLOG.PATH          | путь к файлу лога. по умолчанию: `fname & ".log"`|
|  eLOG.APPEND        | пересоздавать/добавлять лог-файл                 |

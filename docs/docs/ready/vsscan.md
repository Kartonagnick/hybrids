[![S]][M] vsscan v0.0.1
=======================
Гибрид предназначен для формирования списка исходников банановых проектов.  
Банановый проект - это проект с++, использующий в качестве системы сборки Banana.Props  
<br/>


Пример использования
--------------------
Работает гибрид полностью в автоматическом режиме.  
1. Копируем файл гибрида  `ready/vsscan.bat`  в стеш бананового проекта.  
2. Запускаем гибрид на выполнение.  
3. Ожидаемый результат: формируются корректные файлы:  
 - `проект.vcxproj.filters`
 - `sources.props`
<br/>


Управляющие параметры
---------------------

| переменная | назначение                   |
|:----------:|:----------------------------:|
| eDEBUG     | вкл/выкл отладочный вывод    |
| eDIR_WORK  | путь к репозиторию или стешу |

```bat
set "eDEBUG=ON"
set "eDIR_WORK=D:\repo\Bolid\_stash\parametric"
```
